# Multi-Agent AI Playground client

The web client is built with React, TypeScript, and Vite. It visualizes agents and tools connected to the backend hub and provides a chat interface.

From the project root, start the hub and the agents you need, then run:

```sh
npm run client
```

Or run the client directly from this directory:

```sh
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). For backend setup, Google integrations, and GitHub publishing instructions, see the [project README](../README.md).
